## Contract (r10-bridge owns `docs/api.md`)
Commit these first, within about 30 minutes, then write a status line.
- **File:** `GET /agents/:id/file?path=<cwd-relative path>`.
  - Returns text: `{ "path", "content", "size", "truncated", "language"? }`.
  - The path must resolve (realpath) inside the agent's cwd; symlinks can't escape. Otherwise `403`.
  - Cap about 1 MB (`truncated: true`).
  - Binary: `415 unsupported`, except images, which are returned as bytes with their `Content-Type`.
  - Full paths never cross the wire, and the tool summaries are already cwd-relative.
- **Edits:** make sure the `toolCall` block for Edit/Write/MultiEdit carries what the app needs to show a diff: old/new strings, or the written content (capped). Say how in api.md.
- **Plan:**
  - The `Approval` for Claude's ExitPlanMode gets `plan` (markdown).
  - The `ExitPlanMode` `toolCall` in history carries the plan too, so it's still visible after approval.
  - Source: the tool input, or the plan file it wrote.
